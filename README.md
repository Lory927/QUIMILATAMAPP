# 🧪 QuimiLATAM — Aprende Química Jugando

**QuimiLATAM** es una aplicación web interactiva de página única (SPA) diseñada para transformar el aprendizaje de la química en estudiantes de educación secundaria y preparatoria (13 a 18 años) en América Latina.

## 🚀 Características Principales

- **🥽 Laboratorio Virtual Interactivo:** Simulaciones guiadas paso a paso con selector aleatorio de experimentos (pH, conservación de materia de Lavoisier, velocidad de reacción por temperatura, escala de densidad y titulación ácido-base).
- **🛠️ Editor de Moléculas en Red (Grid Canvas):** Área de trabajo matricial para colocar átomos, trazar enlaces simples/dobles/triples y validar valencias y fórmulas en tiempo real.
- **📚 Biblioteca de Teoría Dinámica:** Lecciones interactivas con diagramas SVG en vivo (Modelo de Bohr, tendencias periódicas, enlace covalente vs iónico, balanza estequiométrica y solubilidad) con mini-quizzes de autoevaluación.
- **📱 Mobile-First & Accessible:** Interfaz adaptable optimizada para celulares y pantallas de escritorio, con soporte nativo para Modo Oscuro y paleta accesible (WCAG AA).
- **⚡ Zero Backend / 100% Client-Side:** Funciona completamente en el navegador sin dependencias de servidores externos o bases de datos, con almacenamiento local en `localStorage`.

---

## 🛠️ Tecnologías Utilizadas

- **Frontend:** HTML5, JavaScript (ES6+ Native Engine)
- **Estilos & UI:** Tailwind CSS (CDN), Google Fonts (*Baloo 2* y *Nunito*)
- **Iconografía:** FontAwesome 6
